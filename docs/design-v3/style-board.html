Stray’s Call — v3 style board

Phase A: three variations of one structure — three soft tints (Lavender Dream #B1A9DA, Pale Lemon #FFEDA8, plus a third), one very dark anchor, and a warm cream background. Roughly 60% cream/neutral, 30% soft tints, 10% anchor.

Target: modern, warm, trustworthy, easy — not cute, not clinical, not an alarm. Only Critical is red. Not part of the app; self-contained (fonts embedded). Every text pair below passes WCAG AA (checked when this file was generated).
